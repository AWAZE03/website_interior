✨ SRK INTERIOR
Premium Wall & Ceiling Design Showcase Website
Elevating spaces with premium textures, luxury finishes, and modern interior aesthetics.

🏛️ About The Project
SRK INTERIOR is a modern, luxury-inspired website designed to showcase premium wall panels, fluted louvers, marble-finish sheets, and ceiling lighting solutions.
This project blends:
* 🎨 Elegant typography
* 🌟 Cinematic animations
* 🪵 Premium material aesthetics
* 🖥️ Responsive modern UI
* ⚡ Smooth scrolling & parallax effects
Built to reflect the sophistication of a high-end interior showroom.

🎥 Live Experience
Designed to feel like walking inside a luxury interior showroom.
* Cinematic hero section with GSAP animation
* Floating elements with organic motion
* Scroll-triggered reveals
* Elegant dark showroom section
* Smooth infinite marquee
* Premium call-to-action sections

🛠️ Built With
* HTML5
* Tailwind CSS
* GSAP (GreenSock Animation Platform)
* ScrollTrigger
* Lucide Icons
* Google Fonts (Playfair Display & Outfit)
